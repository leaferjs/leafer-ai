# Leafer AI

**✨ 借助 AI，人人皆可创造！**

LeaferJS 官方 Skills，让 AI 借助官方文档、示例和插件，帮你轻松构建可交互、可编辑的图形应用。

🎨 海报编辑器 · 🪄 无限画布 · 🧠 思维导图 · 🎬 视频分镜 · 🎮 小游戏

## 🚀 零基础上手，3 步开始创作

**不会编程也没关系，告诉 AI 你想做什么，剩下的交给它！**

### 1. 🤖 让 AI 帮你安装

打开 Codex、Claude Code 或 Cursor 等支持 Skills 和命令执行的 AI 编程工具，创建一个空文件夹并打开。

**复制下面的内容，发送给 AI：**

```text
请帮我安装 LeaferJS Skill：
npx skills add leaferjs/leafer-ai

请检查环境、安装缺少的依赖，并确认安装成功。
```

按照 AI 的提示完成安装，就可以开始创作啦！

### 2. 🎨 告诉 AI，你想做什么

安装成功后，在当前文件夹中开启新对话。

**试试让 AI 帮你做一个旅行照片墙：**

```text
使用 leaferjs，帮我做一个漂亮的旅行照片墙。照片可以随机角度摆放，支持添加、拖动、缩放、旋转和修改文字。画布可以缩放平移，还能导出图片。

优先使用现有功能和插件，帮我完成开发、运行和预览。
```

🎉 打开 AI 提供的预览，就能体验自己的作品！

### 3. 🪄 继续聊天，完善作品

想增加新功能？直接告诉 AI：

```text
给照片墙增加自由涂鸦功能，支持调整画笔大小和颜色，模拟压感和自动防抖。
```

就这样，不断完善你的创意！✨

💡 **小提示：** 遇到问题，把截图或报错发给 AI；下次继续创作，打开原来的项目文件夹即可。

## 💻 开发者快速开始

在项目根目录运行以下命令可以直接安装 Skills：

```bash
npx skills add leaferjs/leafer-ai
```

## ⚡ 按需读取，更省 Token

LeaferJS Skill 包含丰富的官方文档、示例和插件知识，但**文件多 ≠ Token 消耗多**。

我们专门为 AI 建立了 3 类文档索引：

- 📖 **开发指南索引** — 快速找到教程、指南和常见场景
- 🧩 **API 参考索引** — 精准查找元素、属性、方法和事件
- 🔌 **插件文档索引** — 优先使用现有插件，避免重复造轮子

AI 可以先通过本地关键词搜索或文档索引定位，再按需读取相关文档和示例，无需一次性加载整个知识库，减少 Token 消耗。

📚 知识库同步自 [LeaferJS AI Docs](https://github.com/leaferjs/ai-docs)，并持续自动更新。

## 🔄 保持更新

**让 AI 帮你更新：**

```text
请帮我更新 LeaferJS Skill 到最新版，并确认更新成功。
```

**或自己执行：**

```bash
npx skills update leaferjs
```

更新后开启新对话即可。Skill 更新不会自动升级项目中的 LeaferJS 依赖。
